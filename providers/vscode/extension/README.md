# Gitea Codespace

This extension adds a **Codespace Ports** view to the browser IDE. Use it to
publish an application port, change its name or access level, and stop
publishing it. These actions are also available in the command palette.
The port list refreshes when opened or when the editor regains focus; a failed
refresh keeps the previous list and marks its status as out of date.

Compatible Kata runtimes also show **USB Devices**, with source groups,
refresh, attach and detach actions. Local device status refreshes every ten
seconds while the view is visible and the editor has focus. Establish a named
USB/IP SSH reverse tunnel before attaching a device. Codespace installs and
updates the extension automatically.
