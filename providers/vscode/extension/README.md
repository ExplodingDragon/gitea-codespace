# Gitea Codespace

This extension adds a **Codespace Ports** view to the browser IDE. Use it to
publish an application port, change its name or access level, and stop
publishing it. Compatible Kata runtimes also show **USB Devices**, with
source groups, refresh, attach and detach actions. Establish a named USB/IP SSH
reverse tunnel before attaching a device. Codespace installs and updates the
extension automatically.
